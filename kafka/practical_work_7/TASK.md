# Практическая работа 7

Нужно выполнить два задания в Yandex Cloud:

1. Развернуть кластер Managed Service for Apache Kafka из трёх брокеров,
   настроить репликацию, хранение, Schema Registry, продюсер и консьюмер.
2. Интегрировать Kafka с Apache NiFi или Hadoop и подтвердить передачу данных.

Обязательные материалы:

- описание ресурсов и конфигурации;
- топик с тремя партициями и фактором репликации 3;
- настройки `cleanup.policy`, `retention.ms`, `segment.bytes`;
- зарегистрированная схема и ответы API Schema Registry;
- вывод `kafka-topics.sh --describe`;
- код и логи продюсера/консьюмера;
- конфигурация, логи и скриншоты внешней системы;
- подтверждение поступления сообщений в Kafka.

Выбранная внешняя система: Apache NiFi.
